Bomb Farm code information can change quickly. Before using or sharing a code, check where it came from, what reward it claims, and whether the expiration time has already passed.

## Freshness check

Checked September 4, 2026:

- Official source: Steam News API / Community Announcements.
- Relevant announcement: Weekly Ranking Rewards and General Improvements, published September 2, 2026.
- Code named by the announcement: KENDO.
- Reward described by the announcement: 3 hours of +100% Gold, XP, and Drop.
- Availability described by the announcement: once per account until September 8, 2026 at 11:59 PM UTC-3.

Because the code window is time-sensitive, recheck Steam and the live client before relying on it and again after September 8, 2026. If the live client rejects the code or the announcement changes, treat the older note as stale.

## How codes are verified

Active and expired code claims should come from official Steam announcements, developer posts, or direct in-game confirmation. A copied community page can help you find a lead, but it is not enough by itself.

For each code, keep these facts together:

- Code text exactly as published.
- Source URL and source date.
- Reward text exactly as described by the source.
- Expiration date, timezone, and account limit when stated.
- Last checked date.

## Friend codes and community posts

Steam discussions show players asking where to redeem codes and sharing friend-code questions. Treat friend-code rewards as uncertain unless the current game or an official source explains them.

## Related update checks

When update notes mention rewards, weekly events, stash changes, or Market changes, recheck code status before using old information.

Use [Latest Update](/updates/latest/) for the newest official announcement found during the last check, and use [Steam Market Safety](/guides/steam-market/) when code rewards or item handling connect to inventory behavior.
