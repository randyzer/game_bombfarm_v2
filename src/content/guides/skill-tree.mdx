Bomb Farm includes a large account skill tree. Steam describes it as inspired by Path of Exile, but the store page does not provide node values, build orders, or best paths. Check those details in the current game.

## What to know first

Bomb Farm has a large account skill tree that supports progression alongside heroes, gear, gems, Ritual, and stage progress. Check the current game client for the exact node list, node costs, numerical bonuses, and order before committing resources.

## Safe planning approach

Use the skill tree as a persistent progression system. Before spending resources, read the current in-game node text and compare recent Steam updates if they mention balance, rewards, or system behavior. If a guide gives a precise route without a source date, treat it as a suggestion, not a verified fact.

## Related systems

Skill choices should be understood alongside hero roles, gear, rituals, and three-team energy rotation.

- [Hero Roles](/heroes/roles/) explains the verified role labels without ranking heroes.

## What to check before following a build

If a build claims node-by-node data, build orders, numerical bonuses, or optimal paths, look for a date and source. Patch changes can make skill-tree advice age badly.
