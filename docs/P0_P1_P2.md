# P0 / P1 / P2 Roadmap - v2.2

## Important Principle

P0/P1/P2 describes evidence/readiness depth, not simply whether an entire page may exist.

Separate:

```text
Page existence
Claim completeness
Database completeness
Meta/recommendation readiness
```

## P0 - Launch-Useful Coverage

- enough reliable public facts to answer a real player intent;
- no unsupported claims;
- strong player/structural/competitive value.
