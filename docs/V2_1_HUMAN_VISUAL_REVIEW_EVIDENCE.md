## Capture Method

- Desktop first-view screenshots use an exact 1440 x 900 browser content area.
- Mobile pages were rendered with an exact 390 x 844 Chrome mobile/touch emulation. The browser tool included the 500px Agent Window in ordinary-height PNG output, so the final files are unscaled crops of the leftmost exact 390 x 844 emulated content area.
- The 360px homepage uses the same method with a verified 360 x 800 emulated viewport and no scaling.
- The homepage full-page images were captured as two unscaled browser segments because the browser viewport cap is 7680px. The sticky header was hidden only for the second segment so that the assembled full page contains one header. The join areas were inspected separately and contain no repeated header, missing content, or visible discontinuity.
- The Guides full-page image fits in one tall production-rendered viewport and required no stitching.
- Representative media screenshots scroll the requested figure to the center with browser-runtime `scroll-behavior: auto`; no source or stylesheet was changed.
- Contact sheets were assembled from the final PNG files with the already-installed Pillow runtime. No package or project dependency was added.
